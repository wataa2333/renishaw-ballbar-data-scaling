# QC20 三种倍率文件

本目录包含三套互相独立的实验文件：

| 文件夹 | 实时位移源值 | 正式采集样本 |
|---|---:|---:|
| `QC20_倍率0.75` | 原值 × 0.75 | 原值 × 0.75 |
| `QC20_倍率0.25` | 原值 × 0.25 | 原值 × 0.25 |
| `QC20_倍率0.10` | 原值 × 0.10 | 原值 × 0.10 |

每一档都包含两份必须配套使用的 DLL、两份原版恢复文件、安装说明和核验记录。

## 重要规则

1. 一次只能选择一档。
2. 必须同时替换所选档位 `01_修改版_复制到Application` 中的两份 DLL。
3. 不得把不同档位的 DLL 混合使用。
4. 只面向 QC20；不要用于 QC10。
5. 原版文件版本或 SHA-256 不一致时不要安装。
6. 修改会使原本带 Authenticode 签名的 `Renishaw.Calibration.Ballbar.dll` 变为未签名，受 WDAC、AppLocker 或安全软件限制的电脑可能拒绝加载。
7. 这些文件仅用于研究和内部验证，不得用于正式校准、合格判定、计量溯源、验收或对外报告。

缩放点位于实时读取源和正式采集返回样本。线性位移/偏差幅值及其线性派生结果会随倍率变化；角度、温度、测试半径、进给率、日期、百分比和非线性诊断分类不应理解为整体按倍率变化。带标称长度或校准偏置的显示公式只缩放位移源项，不保证整个屏幕表达式严格等比例。
