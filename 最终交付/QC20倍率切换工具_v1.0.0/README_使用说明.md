# 雷尼绍QC20球杆仪位移偏差数据倍率切换工具

版本：1.0.0  
制作人：wataa  
邮箱：wataa2333@gmail.com

## 启动

本工具是免安装单 EXE，面向 Windows 10/11。直接运行：

```text
雷尼绍QC20球杆仪位移偏差数据倍率切换工具.exe
```

首次进入需要输入 Google Authenticator 当前显示的 6 位动态口令。Authenticator 中必须事先添加与本次构建相同的设置密钥，类型选择“基于时间”。动态口令每 30 秒更新；手机和电脑系统时间必须准确。

连续输错 5 次会临时锁定 60 秒。工具支持完全离线验证。

## 使用

1. 选择 Renishaw Ballbar 20 根目录或其 `Application` 目录。
2. 点击“检测目录”，确认显示“目录有效”。
3. 选择倍率：
   - 手动输入：1%–500%；
   - 预设列表：1%、5%、10%、20%、25%、30%、40%、50%、60%、75%、80%、90%、200%、250%、300%、400%、500%。
4. 点击“应用所选倍率”。
5. 如果 Renishaw Ballbar 20 正在运行，工具会列出进程并询问是否结束；取消则不会修改。
6. 工具首次操作会验证并备份两份原版 DLL，然后从原版备份生成目标倍率，避免重复叠乘。
7. 替换后自动验证两份 DLL 的 SHA-256；任一步骤失败会尝试同时回滚两份文件。

手动输入 100% 会恢复原版，而不是生成一个失去原厂签名的“×1”修改版。

## 恢复原版

点击醒目的红色“恢复原版”按钮。工具会同时恢复：

```text
Renishaw.Calibration.Ballbar.dll
Renishaw.Calibration.Ballbar.BallbarDeviceService.dll
```

没有通过 SHA-256 验证的可靠备份时，工具拒绝恢复。

## 手动替换包

点击“生成手动替换包”并选择输出位置。此功能不会修改当前软件目录，会生成：

```text
01_修改版_复制到Application\
02_原版备份_用于恢复\
SHA256SUMS.txt
手动替换说明.txt
```

两份 DLL 必须成套替换，不得跨倍率混用。

## 日志与备份

优先使用：

```text
EXE所在目录\Data\Logs
EXE所在目录\Data\Backup
```

EXE 所在目录不可写时，回退到：

```text
C:\ProgramData\QC20倍率切换工具
```

日志不记录动态口令或密钥。

## 权限

程序默认以普通权限启动。目标目录可写时不会弹出 UAC；只有实际写权限不足时，才会询问是否以管理员身份重新启动。重新启动后需要再次输入动态口令。

## 安全和兼容性

- 最终 EXE 当前没有 Authenticode 证书签名，安全策略严格的电脑可能提示或拦截。
- 修改后的 Renishaw DLL 不再具有雷尼绍原厂 Authenticode 签名。
- 只接受已核验版本：
  - `Ballbar.dll`：1.4.8382.25726；
  - `BallbarDeviceService.dll`：1.2.8382.25728。
- 原版哈希不同、首次操作已是未知修改版或备份损坏时，工具会停止操作。
- 本次构建使用的密钥已经在对话中出现，且长度为 80 bit；适合当前测试，不应视为长期高安全性正式密钥。

## 计量限制

本工具及其输出仅限学习研究测试，不得用于正式校准、计量溯源、合格判定、设备验收或对外合规报告。

缩放点位于 QC20 实时位移读取源和正式采集样本。线性位移/偏差幅值及其线性派生结果会随倍率变化；角度、温度、测试半径、进给率、日期、百分比和非线性分类不按倍率整体变化。
