# 最终测试报告

测试日期：2026-08-02  
版本：1.0.0

## 构建与便携性

- 使用 Windows 自带 .NET Framework C# 编译器构建。
- 最终运行目录只需要一个 EXE。
- 不依赖 .NET SDK、安装程序或同目录 `dnlib.dll`。
- Windows 10/11 使用原生 Windows Forms；Windows 11 尝试启用 Mica、圆角和深色标题栏，不支持的系统会安全回退。

## 登录和资源

- 登录窗口成功启动并持续响应。
- 加密头像资源成功解密并绘制为圆形。
- 使用独立 TOTP 计算结果自动输入，成功进入主界面。
- TOTP：HMAC-SHA1、6 位、30 秒、前后各一个时间窗口。
- Base32 明文密钥扫描：源码、生成资源和 EXE 中均未发现。
- `dnlib` 与头像采用 AES-256-CBC 加密，密文使用 HMAC-SHA256 验证完整性。

## 程序集结构验证

在 1%、50%、500% 三档分别验证：

- 程序集标识一致；
- 公开 API 一致；
- 资源名称一致；
- 每份 DLL 只有一个预期方法发生变化；
- `Ballbar.dll`：`BallbarInstrument.ReadRecord(...)`；
- `BallbarDeviceService.dll`：`QC20BallbarDevice.get_LatestReading()`。

## 模拟采集与实时读取

| 倍率 | 正式采集输入 `-4, 0.125, 8` | 实时输入 `12.5` |
|---:|---|---:|
| 1% | `-0.04, 0.00125, 0.08` | `0.125` |
| 50% | `-2, 0.0625, 4` | `6.25` |
| 500% | `-20, 0.625, 40` | `62.5` |

三档的返回样本数量保持不变，目标数组有效区以外的哨兵值未改变。

## 备份、替换和恢复

- 从核验原版成功建立外部备份。
- 1%、50%、500% 均成功从原版备份生成，不存在倍率叠乘。
- 双文件替换后 SHA-256 与生成文件一致。
- 500% 手动替换包包含两份修改版、两份恢复版、哈希和说明。
- 原版恢复后两份哈希分别回到：
  - `12B679343DD871B0FF4F39A7E5A404266EB3AA7AA55BB3D2F86B2F4884B8A255`
  - `7494DF3816A27D4EC90449B0B836D66C667490357D6B2784EA47080CB4C7B86B`
