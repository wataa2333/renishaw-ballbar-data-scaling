# QC20 采集数据 50% 修改版

## 文件

- `Renishaw.Calibration.Ballbar.dll`：修改版，使用时替换 `Application` 目录中的同名文件。
- `Renishaw.Calibration.Ballbar.original.dll`：未经修改的原版备份。

原安装目录中的 DLL 没有被本次操作覆盖。

## 修改内容

程序集版本保持为 `1.4.8382.25726`。

修改位置：

```text
Renishaw.Calibration.Ballbar.BallbarInstrument.ReadRecord(
    int index,
    double[] array,
    int arrayIndex,
    int count)
```

方法从采集缓存读取样本后，仅对实际返回的样本执行：

```csharp
array[i] *= 0.5;
```

这会影响修改后新采集测试的分析、曲线、报告和保存结果，不会自动修改已有历史文件。实时 `LatestReading` 不在本次修改范围内。

## 使用方法

1. 退出 Renishaw Ballbar 20。
2. 备份实际安装目录中的 `Application\Renishaw.Calibration.Ballbar.dll`。
3. 将本目录的修改版 `Renishaw.Calibration.Ballbar.dll` 复制到实际安装目录的 `Application`，覆盖同名文件。
4. 启动软件，以已知测试数据验证缩放结果。
5. 如果软件不能启动或企业安全策略拦截，立即恢复原 DLL。

建议先在完整的软件副本或非生产测量电脑上验证，不要把修改后的结果当作未经处理的原始计量数据。

## 无硬件动态模拟

使用真实的 `TriggeredBufferingFilter` 构造内存采集缓存，并分别加载原版和修改版程序集调用真实的 `BallbarInstrument.ReadRecord()`。

测试条件：

```text
缓存样本       10, -4, 0.125, 8, 100
读取起点       1
目标数组起点   2
请求数量       3
```

结果：

```text
原版返回数量   3
原版输出       -4, 0.125, 8

修改版返回数量 3
修改版输出     -2, 0.0625, 4
```

目标数组读取区域以外的哨兵值保持不变，说明补丁只处理实际返回的采集样本，没有越界修改。

## ISO 230 分析及报告控件模拟

使用软件自带的真实 `Iso230V2005Analysis` 核心算法，对相同的 360° CW/CCW 合成采样分别按 `1.0` 和 `0.5` 输入。

核心结果示例：

```text
指标                         原始输入       0.5 输入       比例
CW 圆度偏差                  10.301193      5.150597       0.5
CW 最大径向偏差               5.150596      2.575298       0.5
CW 最小径向偏差              -5.150598     -2.575299       0.5
CCW 圆度偏差                 10.294984      5.147492       0.5
双向圆度偏差                  0.090067      0.045034       0.5
```

最大/最小偏差发生角度保持不变，这是预期行为：缩放幅值不改变特征所在角度。

随后实例化软件自带的真实 ISO 230 WinForms 报告控件，确认显示标签得到：

```text
圆度偏差       5.150596
最大径向偏差   2.575298 @ 269.750693°
最小径向偏差  -2.575299 @ 89.252078°
双向圆度偏差   0.045034
```

因此已验证数值链路：

```text
采集样本 × 0.5
→ ISO 230 核心分析
→ 报告特征结果
→ 报告控件标签
```

本模拟没有启动完整应用壳，也未测试极坐标图截图、HTML 打印布局、物理打印机或企业安全策略。
