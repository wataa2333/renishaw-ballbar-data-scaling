# 数据源与补丁覆盖范围审计

## 结论

对于“连接 QC20 后新执行的一次正式球杆仪测试”，测试结束时写入
`IRunResult.Readings` 的采集样本只有一条路径：

```text
QC20Ballbar
→ BallbarInstrument 采集缓存
→ QC20BallbarDevice.m_instrument_FeedOutDetected()
→ QC20BallbarDevice.PopulateRunResult()
→ BallbarInstrument.ReadRecord()
→ IRunResult.Readings.Add()
```

修改版位于上述 `BallbarInstrument.ReadRecord()`，因此覆盖 QC20 新测试的正式采集样本。

## 全程序集调用点

扫描 `Application` 和 `Simulator` 中所有可读取的 .NET DLL/EXE 后，
`BallbarInstrument.ReadRecord()` 的业务调用者只有：

```text
QC10BallbarDevice.PopulateRunResult()
QC20BallbarDevice.PopulateRunResult()
```

用户只使用 QC20，因此有效调用点只有
`QC20BallbarDevice.PopulateRunResult()`。

QC20 的 `CaptureAsync` 状态机对 `IRunResult.Readings` 的直接操作是
`Clear()`，没有另一条添加采样的代码；实际添加样本发生在
`PopulateRunResult()`。

`BallbarInstrument.CalculateIndices()` 会直接调用底层
`BufferingFilter.ReadBuffer()`，但它只用于确定采集起止索引，不负责把样本
写入测试结果。本补丁没有改变该路径，因此不会改变触发和索引计算。

## 不经过补丁的其他数据入口

这些属于软件中的其他数据来源，但不是 QC20 新测试的正式采集写入路径：

1. **实时读数**

   ```text
   QC20Ballbar.get_LatestReading()
   → QC20BallbarDevice.get_LatestReading()
   → CaptureBallbarViewPresenter / MonitorBallbarViewPresenter
   ```

   它用于连接、监视和采集过程中的实时界面，不经过 `ReadRecord()`。

2. **XML 结果文件**

   ```text
   XmlDocumentFormatter.PopulateRunResult()
   → ParseReadingsString()
   → IRunResult.Readings
   ```

   导入旧 XML 文件时不会自动乘以 0.5。修改后新保存的 XML 已经包含缩放后的样本，
   再次打开时仍是缩放后的值。

3. **RTB 旧格式文件**

   ```text
   RtbDocumentFormatter.LoadRtbRunResults()
   → RtbDocumentFormatter.PopulateRunResult()
   → IRunResult.Readings
   ```

   导入旧 RTB 文件不会经过补丁。

4. **旧 COM/Legacy 数据**

   ```text
   ComRunResultAdapter.AddReading()
   → IRunResult.Readings
   ```

   旧格式转换数据不会经过补丁。

5. **软件模拟器**

   模拟器使用独立的 `clsSimulationEngine`，包含 `SimulateCWRun()`、
   `SimulateCCRun()`、`CreateTestResultsObjects()` 和独立 RTB 写入器，
   不调用 `BallbarInstrument.ReadRecord()`。

6. **分析生成的模拟曲线**

   `ISimulationResult.Readings` 是分析算法生成的诊断模拟结果，不是 QC20 实测样本。

7. **已有历史结果**

   历史或已保存文件不会因替换 DLL 而自动重写。

## 覆盖范围表

| 数据场景 | 是否经过修改版 `ReadRecord()` |
|---|---|
| QC20 新测试最终采集样本 | 是 |
| QC20 新测试分析结果 | 间接经过，使用已缩放样本 |
| QC20 新测试报告和曲线 | 间接经过，使用已缩放样本 |
| QC20 实时 `LatestReading` | 否 |
| 重新打开修改后保存的新结果 | 文件中已经是缩放值 |
| 导入修改前的 XML/RTB | 否 |
| 软件模拟器生成的数据 | 否 |
| 旧 COM/Legacy 数据 | 否 |
| 已有历史记录 | 否 |

## 最终判断

不能说它是整个软件唯一的数据来源，因为软件还支持实时读数、文件导入、模拟器和
旧格式转换。

可以确认：在当前版本中，对于 QC20 实机新测试写入正式
`RunResult.Readings` 的设备采集路径，`BallbarInstrument.ReadRecord()` 是唯一读取入口。
